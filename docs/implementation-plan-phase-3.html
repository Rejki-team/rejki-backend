W3B-06 PATCH iklan — update handler di 4 iklan service + ownership check SQL 4 iklan services P1

W3B-07 Password reset flow — OTP-based reset password + confirm-reset auth-service P1
OpenSpec change baru: ws-password-reset
Target gap: D2
Handler: POST /api/v1/auth/reset-password — terima email, kirim OTP, timing-safe response (anti-enumeration)
Handler: POST /api/v1/auth/confirm-reset — terima email + OTP + new_password, consume OTP, update password_hash
Rate limit: 3 reset request per email per jam, 5 OTP verify attempt (sama dengan register)
Audit log: event password_reset_requested, password_changed (via W3B-04)
Notification: kirim OTP via email/SMS (pakai notification-service)
Invalidate semua refresh token setelah password berubah (security — session hijacking prevention)
Test: unit test reset flow, integration test OTP consume + password verify + token invalidation

W3C — mayoritas independent. Hanya W3C-10 (integration test) dan W3C-11 (region validation) yang ada dependency, tapi tidak block start.
W3D — mayoritas independent. Hanya W3D-12 (CEO analytics) yang nunggu W3A-03 + W3B-05.
Total parallel capacity: 5-7 task bisa dikerjakan bersamaan jika ada multiple developers.
