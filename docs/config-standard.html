Phase 2 — Configuration Standard v2

Centralized TOML Configuration Standard

Standar konfigurasi terpusat via common_config::AppConfig::load() — menggantikan scattered std::env::var(). Satu struct, 9 sub-config, auto-deteksi environment, fail-fast pada startup.

Phase 2 All Services common-config crate

🧭Prinsip

✅
Dokumen ini adalah Single Source of Truth untuk konfigurasi

Struktur AppConfig, 9 sub-config domain, naming convention env var, prinsip fail-fast — semuanya didefinisikan di sini. Implementasi ada di common/config/src/.

Single entry pointSemua service memanggil AppConfig::load() sekali di awal main.rs. Tidak ada scattered std::env::var() di masing-masing service.
Fail-fast on startupField required (DATABASE_URL, MINIO_ENDPOINT, dll.) panic saat startup jika tidak diset. Optional (REDIS_URL, SMTP_HOST) menggunakan Option atau default.
SCREAMING_SNAKE_CASE env varsSemua environment variable menggunakan format SCREAMING_SNAKE_CASE. Prefix domain: DATABASE_, JWT_, REDIS_, MINIO_, dll.
Prefixed vars untuk migrationREJKI_* prefix menimpa bare vars — misal REJKI_DATABASE_URL override DATABASE_URL. Digunakan saat migrasi ke namespaced vars.
Concrete types, not stringsConfig disimpan sebagai tipe konkret: u16 untuk port, PathBuf untuk path, Vec<String> untuk list, i64 untuk TTL.
No hardcoded valuesTidak ada konstanta yang ditulis inline di kode. Semua nilai (TTL, port, hostname) berasal dari config struct — bisa dibaca dari env var atau pakai default.

Config loading via config crate

Flow loading config
// AppConfig::load() flow:
// 1. Load .env file (development only, silent fail jika tidak ada)
dotenvy::dotenv().ok();

// 2. Build config dari dua sumber env vars
let s = config::Config::builder()
    .add_source(config::Environment::default()           // bare vars: DATABASE_URL, REDIS_URL...
        .try_parsing(true))
    .add_source(config::Environment::with_prefix("REJKI")  // prefixed: REJKI_DATABASE_URL, dll.
        .separator("_")
        .try_parsing(true))
    .build()
    .expect("gagal build konfigurasi dari environment");

// 3. Extract + validate setiap field
let db_url: String = s.get("database_url").expect("DATABASE_URL tidak di-set");

💡
CORS_ALLOWED_ORIGINS adalah comma-separated

Diparse dari string ke Vec<String> saat AppConfig::load(). Contoh: CORS_ALLOWED_ORIGINS=https://rejki.id,https://app.rejki.id → ["https://rejki.id", "https://app.rejki.id"].

💥Fail-Fast Validation

Semua validasi config dilakukan di AppConfig::load() sebelum server mulai menerima request.

Jenis ValidasiImplementasiContoh Error
Required field tidak adas.get("key").expect("KEY tidak di-set")panicked: DATABASE_URL tidak di-set
Config source build gagal.build().expect("gagal build konfigurasi")panicked: gagal build konfigurasi dari environment
CORS kosongassert!(!cors_allowed_origins.is_empty())panicked: CORS_ALLOWED_ORIGINS tidak boleh kosong
APP_ENV tidak validload_app_env() panic pada nilai tidak dikenalpanicked: APP_ENV tidak valid: 'staging' (harus development/production)
Fail-Open Pattern
// Optional services menggunakan .ok() = None jika tidak di-set
// Service menangani None dengan graceful degradation
redis: RedisConfig {
    url: s.get("redis_url").ok(),  // None → rate limiter disabled, log warning
},

smtp: SmtpConfig {
    host: s.get("smtp_host").ok(),  // None → email notifikasi disabled, log warning
},

otel: OtelConfig {
    exporter_otlp_endpoint: s.get("otel_exporter_otlp_endpoint").ok(), // None → standard tracing only
},
✅
Panic saat startup = aman. Panic saat runtime = berbahaya.

Service yang gagal start karena missing config akan segera terdeteksi saat deployment. Service yang start lalu crash di tengah request karena missing config adalah bug yang lebih buruk — request user hilang, data mungkin setengah tersimpan.

⚙️Implementasi Rust

common/config/src/lib.rs — Config loading
// common/config/src/lib.rs — single source of truth untuk semua konfigurasi
pub struct AppConfig {
    pub app_env:  AppEnv,
    pub app_port: u16,

    // Sub-config — setiap domain punya struct sendiri
    pub database: DatabaseConfig,
    pub jwt:      JwtConfig,
    pub redis:    RedisConfig,
    pub minio:    MinioConfig,
    pub smtp:     SmtpConfig,
    pub otel:     OtelConfig,
    pub clamav:   ClamavConfig,
    pub cors:     CorsConfig,
}

impl AppConfig {
    pub fn load() -> Self {
        dotenvy::dotenv().ok();

        let s = config::Config::builder()
            .add_source(config::Environment::default().try_parsing(true))
            .add_source(config::Environment::with_prefix("REJKI").separator("_").try_parsing(true))
            .build()
            .expect("gagal build konfigurasi dari environment");

        // APP_ENV: development atau production
        let app_env_raw: String = s.get("app_env").unwrap_or_else(|_| "development".into());
        let app_env = match app_env_raw.to_lowercase().as_str() {
            "production" => AppEnv::Production,
            _ => AppEnv::Development,
        };

        Self {
            app_env,
            app_port: s.get("app_port").unwrap_or(8080u16),

            database: DatabaseConfig {
                url:       s.get("database_url").expect("DATABASE_URL tidak di-set"),
                pool_size: s.get("database_pool_size").unwrap_or(10u32),
            },
            jwt: JwtConfig { /* ... */ },
            // ... 7 sub-config lainnya
        }
    }
}
Service main.rs — Usage pattern
// rejki-app/src/main.rs
#[tokio::main]
async fn main() {
    // 1. Load semua konfigurasi — panic disini jika ada yang tidak valid
    let cfg = common_config::AppConfig::load();
    let is_prod = cfg.is_production();

    // 2. Init tracing — OTEL endpoint dari config
    common_tracing::init_tracing(&cfg.otel, is_prod);

    // 3. Init database — URL dari config
    let pool = sqlx::PgPool::connect(&cfg.database.url).await
        .expect("gagal connect ke DB");

    // 4. Init JWT — key path + TTL dari config
    let (private_pem, public_pem) = cfg.jwt.load_keys()
        .expect("gagal load JWT keys");
    let jwt = Arc::new(JwtService::from_keys(
        &private_pem, &public_pem,
        cfg.jwt.access_ttl_secs, cfg.jwt.refresh_ttl_secs,
    ));

    // 5. Rate limiter — Redis URL optional
    let limiter = common_rate_limit::OtpRateLimiter::new(cfg.redis.url);

    // 6. CORS — origins dari config
    // TIDAK lagi: std::env::var("CORS_ALLOWED_ORIGINS").unwrap_or(...)
    let cors = build_cors_layer(&cfg.cors, is_prod);

    // 7. Start server — port dari config
    let listener = tokio::net::TcpListener::bind(
        format!("0.0.0.0:{}", cfg.app_port)
    ).await.unwrap();
}
